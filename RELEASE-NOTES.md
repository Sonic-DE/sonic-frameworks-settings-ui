# Sonic Frameworks Settings UI Release Notes

Sonic Frameworks Settings UI provides the building blocks for settings dialogs, color schemes and recent-file menus in SonicDE apps.

## 6.31.0.1 (2026-11-10)

- Files you open in apps now show up in SonicDE's recent documents and activity history.
- The "About KDE" action in apps is now "About SonicDE", with the SonicDE icon.

## 6.31.0 (2026-10-20)

- Behind the scenes: version number updated for this release.

## 6.30.0 (2026-09-12)

- Behind the scenes: version number updated for this release.

## 6.29.0 (2026-08-07)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.28.0.1 (2026-08-04)

- Apps now fall back to SonicDE's Silver style instead of Breeze when no style is chosen or the chosen one is missing.

## 6.28.0 (2026-07-02)

- Behind the scenes: better support for code editors and restored the project's code formatting rules.
